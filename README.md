# Hydra landing page

A responsive single-page marketing site built in React from the [Hydra Landing Page (Community)](https://www.figma.com/design/2RM1vFlJZ5LlOeD6YCheip/Hydra-Landing-Page--Community-) design on Figma. A personal practice project from 2023, built to sharpen Figma-to-code work.

**Live:** https://hydra-landing-page.vercel.app

## What's in it

A responsive hero with layered SVGs, an animated services slider, a reasons slider, a technology section, a contact form, and scroll navigation.

## Stack

React (Create React App), HTML, CSS, JavaScript

## Credit

The design is the Hydra Landing Page (Community) file on Figma, linked above. All design credit goes to its original author. The code is mine.

## Run it locally

npm install, then npm start
